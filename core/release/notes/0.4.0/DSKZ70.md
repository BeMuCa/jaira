- Press Overview in the jaira-cockpit band to see the board at a glance: three columns — In work (held in an agent's lane), Queue (what `jaira next --all` offers) and Put back (backlog and blocked, with the reason) — each row `Handle | lane | title`, and beneath them what was created or put back in the last seven days, by day and with who; it reads the board, so it is the same after a night or a restart. "Put back" is dated by the ticket's last change, since jaira records no time a ticket changed lanes.
- Expect the jaira-teamlead to name, when it starts, the tickets created or put back in the last seven days, by day and with who — the same source and rule as the Overview pane; run `jaira roles install` to get it.
