- To let a teamlead agent merge accepted pull requests, commit a one-line `.jaira/land` saying `agent` to the default branch; without it nothing changes and a person merges. `jaira roles pr-gate --merge <base>` answers whether an agent may merge (every ticket on the branch in done).
- Run `jaira roles install` to get `jaira-teamlead/scripts/land.sh <pr>`: it merges the base into the ticket's branch, regenerates the files `.jaira/land-regenerate` names (`<path>: <command>` per line), pushes, waits for CI and merges where `.jaira/land` allows it, otherwise prints the merge line for you.
- The teamlead role now writes your decisions into the definition of done (`jaira dod --add`), gives work back as note + move + new worker, stacks follow-up work on accepted branches and stages only the ticket's own files when filing away.
