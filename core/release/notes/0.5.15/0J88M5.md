- `/cockpit report <id>` and the cockpit's report tool now show only the agent reports that arrived since the ticket was last read; add `all` (`/cockpit report <id> all`, tool argument `all: true`) to see the older ones too.
- `/cockpit report` without an id now says per ticket how many of its kept reports are new.
- `/cockpit ticket <id>` now counts the reports it shows as read, so the next `/cockpit report <id>` brings only what arrived after it.
