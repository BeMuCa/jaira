- Run `jaira update --roles` to get the PR role's fixed pre-push sequence: it scans every commit of the branch with `scripts/pre-push-scan.sh`, merges the default branch, runs the full suite once, ticks the definition-of-done items that waited for that run, files finished tickets away, scans again and only then pushes.
- Put the strings that must never reach your repository — an employer's or a customer's name, one extended regular expression per line — into `~/.config/jaira/mention-denylist` (or point `JAIRA_MENTION_DENYLIST` at another file), saved as UTF-8 or as UTF-16 with its BOM — any other encoding stops the scan with exit 2; a match in any commit's lines, file names, message or author/committer name and email stops the PR role's push, and the report names only the commit and file, never the text. Without the file the scan says its strings were not checked and goes on.
- Expect a warning, not a stop, when a commit names the machine it was made on; the push goes on.
