- A private board in a directory whose name starts or ends with a space (" sub") is now really kept out of git; run `jaira update` in such a board once: it writes the corrected entry to .git/info/exclude and removes the old entry without the space (`/sub/.jaira/`) that an older jaira wrote, unless a person wrote it or a board in a directory `sub` needs it.
- `jaira update --json` reports the old entry it removed in the new field `ignore_stale_dropped` ("" when it removed none).
