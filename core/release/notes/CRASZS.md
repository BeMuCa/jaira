- Run `jaira pr` to see where the checked-out branch's pull request stands — threads waiting, answered and resolved, comments from others, CI, reviews pending and whether the round is settled; `--all` lists every open one, `--json` gives the same as data.
- Run `jaira pr --watch` under a Monitor to follow a pull request: one line per new comment or review, CI turning red or green again, settled, and it ends by itself once the pull request is merged or closed.
- When the cockpit's line "pull request #N for <ticket> is open - follow it" reaches your teamlead session, start `jaira pr --watch --number N` under a Monitor; the cockpit says it once per pull request, after Accept opened one or when an agent's report names one.
- ! On a board whose `.jaira/pr-when` says signoff, the cockpit's Accept no longer moves the ticket to done straight away: it first opens the pull request (the ticket stays in signoff), and only once that pull request's review round is settled does a further Accept move it to done.
- On a board whose `.jaira/pr-when` says signoff, a pull request merged or closed before you pressed Accept keeps the ticket in signoff while its branch is still ahead of the base (a squash merge, or origin not fetched): move it to done by hand.
