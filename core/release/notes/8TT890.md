- When one milestone lies in two files (`q4-<ID>.md` and `q5-<ID>.md`, left after a rename), every milestone command that writes (`jaira logbook` and `jaira restore` of a milestone included) now refuses with exit 3 (`milestone_twin_files`) and names both files: delete the one that is not the milestone and run the command again. `jaira milestone ls` and the board still show only the first of the two files until then.
- `jaira restore` of a milestone whose ID is already on the board under another name now refuses (exit 5, `not_archived`) and names that file, before anything leaves the logbook: keep the file on the board, or delete it and run the restore again.
