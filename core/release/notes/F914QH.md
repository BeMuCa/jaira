- Group tickets into features with `jaira epic create <name> [id...] --title <t> --description <d>`, `jaira epic add/rm <name> <id>...`, and see how far each one is with `jaira epic ls` and `jaira epic show <name>` (done X of Y, follow-ups through follows:/parent: counted); an epic lives only on the ref `refs/jaira/epics/<name>` and needs a repository with a remote.
- Find the open tickets that belong to no feature with `jaira epic ls --unassigned` (`--json` for scripts).
- On a branch named after a ticket (e.g. `feat/f914qh`), `jaira create` without `--follows` now links the new ticket to that one and says so; pass `--follows none` when the new ticket is unrelated.
