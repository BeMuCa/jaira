- Expect Accept in the jaira-cockpit band to start the next step itself once the ticket is in done: a ticket branch with commits master lacks and no pull request yet gets one opened in a Herdr tab (`/jaira-role-pr <id> --by-person`); otherwise the next ticket from `jaira next` that no agent carries starts as a worker or dispatcher, as your `dispatch` setting says. When that step cannot run (no Herdr, no `gh`/`glab`, no `origin`, nothing to start), the cockpit says why and the ticket stays in done; run `jaira roles install` to get the `pr` lane of spawn.sh.
- Expect Accept to open the pull request of a branch that carries several tickets only once every ticket its commits name is in done — until then it starts the next ticket and says which one the pull request still waits for. "Ahead" counts against the default branch of the repository the pull request goes to (the parent in a fork), fetched first — add the parent as a remote (`git remote add upstream <URL>`) where it is missing; a ticket worked on another ticket's branch finds that branch by the commits naming it.
- Expect `/jaira-role-pr` to file every finished ticket of the branch away (`jaira logbook <ID>`, one `chore(<ID>): file the ticket away…` commit each) before it pushes, so the pull request shows the tickets in done, and to describe every ticket the branch carries; run `jaira roles install` to get it.
