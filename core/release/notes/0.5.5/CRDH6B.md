- Rewrite an epic's title, description or markdown text with `jaira epic set <name> --title <t> --description <d> --body <text>` (or `--body-file <path|->`); the member lines stay as they are, an unknown epic exits 5 and a call naming nothing to set exits 2.
- Read an epic's whole text with `jaira epic show <name>`: it now prints the markdown below the description, and `--json` on every `jaira epic` command carries it as `body`.
- In `jaira web`, open an epic's text under its description (folded until you click "Text") and press "Edit" to change its title, description and text; a save made while somebody else changed the same epic is refused with a message naming what they changed, keeps what you typed, and goes through when you press Save again.
- When two clones change the same epic field at once, look for the block marked `<!-- jaira: changed at the same time -->` under the epic's text: it holds the other clone's version, for you to merge by hand and delete.
- Write a list item that starts with a full ticket id into an epic's text without fear: `jaira epic set --body` and the web form store it as `* <id> …`, so it stays text and does not put that ticket into the epic.
