- Reject a ticket that will not be done with `jaira reject <id> --why <text> --force` (`--kind wontfix|obsolete`, default wontfix; `--duplicate-of <id>` sets duplicate, adds the original to `related`, and exits 5 for an unknown id and 2 for the ticket itself): it writes `rejected-kind`, `rejected-why`, `rejected-by` and `rejected-at` onto the ticket — a reason typed over several lines is written as one — and archives it, so the archive says why; without `--force` it refuses with exit 3 and tells an agent to move the ticket to the human lane with `--question` instead.
- Press `R` on the board or on an open ticket to reject it with a one-line reason; like `jaira reject` it stamps the ticket's commits first, and `x` still only archives.
- Read why an archived ticket was rejected in `jaira archive` (a second line per rejected file, and a new `rejected` object in `--json`) and in `jaira show` (a `rejected` row, and a `rejected` object with kind/why/by/at in every `--json`); `jaira restore` takes the `rejected-*` fields off again.
- Run `jaira update` so the jaira section in CLAUDE.md/AGENTS.md names `jaira reject` and tells agents to ask in the human lane rather than reject.
