- To set up a worker's worktree your own way (the `.env`, ports, anything else), put an executable `.jaira/worktree-setup` in the repository: spawn.sh calls it as `.jaira/worktree-setup <worktree> <slug> <port-offset> <repo-root>` instead of copying `.env` and appending its four port lines, stops before opening a tab when it fails or lacks `chmod +x`, and removes the worktree and branch it just made — run `jaira roles install` again to get it.
