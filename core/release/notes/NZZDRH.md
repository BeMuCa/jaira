- Get the jaira-cockpit mod for the Claude Code session you work from by running `jaira roles install --force` (add `--global` to have it in every project; with `--project` Claude Code loads it once you trust the workspace) and starting a new session; without jaira, `/plugin install jaira-cockpit --marketplace BeMuCa/jaira` installs the same mod. Every text it shows is in English, whatever Claude Code's `language` setting.
- Read agent reports in the cockpit's session as one line each, marked as shortened, and type `/cockpit report <id>` to see them whole; `/cockpit threads` shows the conversation threads a cheap model filed your turns into, `/cockpit ticket <id>` opens a pane with a ticket's reports and usage, and each session adds a row to `~/.jaira/metrics.csv`.
- Look at the one frame titled `jaira-cockpit` above the prompt for the board: its head line counts the workers and reviews at work (Herdr tabs or this session's subagents), the tickets waiting for you — yours by `jaira whoami` and nobody's; your teammates' sit in one line that opens, with Discuss only — and the five-hour and seven-day windows used; the mod no longer writes a status line below the prompt.
- Act on a ticket waiting for you from that frame: Accept, Give back (asks what is missing in a pane of its own), Explain (its chat notes the explanation on the ticket, Read explanation shows it) and Discuss (its chat notes the decision, moves the ticket back itself when that is the decision, tells your session, and Read decision shows it); each chat's tab closes once its note is there, `+N more` opens the tickets beyond the first three, and a failed button opens its error whole in a pane.
- Expect the frame's last line to show context size and prompt-cache time left, with `/compact advised` and a cold cache in the warning colour, and a prompt of yours onto a cold cache with a large context to be held with a choice: send, compact first, start over, cancel.
- Expect nothing of the cockpit in a session that carries a ticket (a worker, lane or dispatcher `spawn.sh` starts): there it only writes the session's record and metrics, and messages to it arrive as written.
- Tell a person's lane from an agent's in `jaira lanes --json` by the new `human_exit` field (true for `signoff` and `human` on the shipped board, also in `jaira lanes show --json`), and open a chat about a ticket with `spawn.sh --no-worktree [--parent <session>] <slug> <id> explain|discuss` — run `jaira roles install --force` (add `--global` if you installed them globally) to get the new `spawn.sh`.
