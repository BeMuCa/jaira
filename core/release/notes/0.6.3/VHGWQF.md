- Press Accept in the cockpit on a ticket whose commits sit on another, differently named branch (a follow-up worked on the branch of the ticket it followed): the move into done now runs in that branch's worktree instead of failing with "git has none for <ID>"; where several branches could carry them, nothing moves and the press names them, so run the move in the right worktree by hand.
- If `jaira move --to done` refuses for want of commits while commits naming the ticket exist on a branch your checkout does not reach, read the branch names it now adds and run the move in that branch's worktree, or merge it first.
