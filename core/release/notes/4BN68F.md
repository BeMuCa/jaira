- Set the editor E opens a ticket in under S, 'Editor (E)': a command with its arguments, e.g. `nvim` or `code --wait`; leave it empty to keep VISUAL, then EDITOR, then git's core.editor.
- Set the program o opens a file from the diff in under S, 'IDE (o in the diff)', as a template with `{file}` and `{line}`; leave it empty to keep `code -g {file}:{line}`.
- When the IDE set for o is not installed, o now opens the file in your editor, without a line number, and the diff title says which program was missing; before, it showed the error and opened nothing.
