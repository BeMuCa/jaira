Run `jaira update --lanes`, then start every `review-verdict` with `accept:` or `send-back:` — a `send-back` verdict now refuses `jaira move` out of review to anything but in-progress (exit 3, code `verdict_sends_back`), and a verdict that starts with neither word refuses the move on (`verdict_unknown`).
- A lane file can name its own verdict words with `verdict-accept: [...]` and `verdict-send-back: [...]`; `jaira show <id> --for-lane review --json` hands them to the reviewer as `verdicts`.
