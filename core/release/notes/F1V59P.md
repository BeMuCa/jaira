- ! Run `jaira update --lanes`, then start every `review-verdict` with `accept:` or `send-back:` — a `send-back` verdict now refuses every `jaira move` past review, from review or from blocked and names in-progress as the way back (exit 3, code `verdict_sends_back`).
- A lane file can name its own verdict words with `verdict-accept: [...]` and `verdict-send-back: [...]`; `jaira show <id> --for-lane review --json` hands them to the reviewer as `verdicts`.
