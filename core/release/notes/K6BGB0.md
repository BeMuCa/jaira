- When a ticket file in your checkout is older than its ref, the board, `jaira list` and `jaira show` now show the ref's lane and state and mark the ticket (`⇣ pull` on the card, `[behind ref: pull it]` in list, `behind-ref: true` in JSON) — run `jaira pull <id>` before writing it, writes stay refused until you do.
- A write on a ticket whose file was overtaken by its ref within the same second (a pull here, a move in another worktree right after) is now refused like any other stale write — run `jaira pull <id>` when jaira says the file is older than its ref, even if both show the same updated-at.
