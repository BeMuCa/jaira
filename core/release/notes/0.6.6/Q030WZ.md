- With `JAIRA_USER` set, the ownership checks of `claim`, `move`, `release` and `pull` and the board's own-ticket view now count as yours only that name and its aliases from `jaira people` — no longer the checkout's git user.email or the names in `~/.jaira/identity`; add a name you still need with `jaira people alias`.
- `jaira whoami` marks the alias file "(not read under JAIRA_USER)" while `JAIRA_USER` is set, and `whoami --json` says so in the new field `alias_file_read`.
