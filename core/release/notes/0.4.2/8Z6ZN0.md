- Install jaira on Windows from PowerShell with `irm https://raw.githubusercontent.com/BeMuCa/jaira/master/scripts/install.ps1 | iex`: it verifies the checksum, puts `jaira.exe` in `%LOCALAPPDATA%\Programs\jaira` (or `JAIRA_INSTALL_DIR`) and adds that folder to your user PATH, no admin rights needed; run it again to update.
