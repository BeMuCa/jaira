- Press Give back in the cockpit on a reviewed ticket to decide each review note on its own row - fix now, follow-up (jaira creates a ticket that follows this one, the note as its context) or accept; Give back sends only the notes marked fix now, and Accept in the same pane records the rest on the ticket.
- Expect each review note to start as accept and a blocker as fix now; a follow-up ticket is created only for a row you turn to follow-up yourself, and the next acceptance of the same ticket starts every note decided before as it was decided, marked "(decided before)".
- Expect the band's Accept to open the review notes instead of accepting when the review names a blocker; accepting a blocker not marked fix now there needs a reason typed into the required field, which goes onto the ticket as a decision note.
- Run 'jaira update --lanes' to get the in-progress prompt that fixes exactly the notes under 'beheben:' of a give-back and leaves accepted and follow-up notes alone.
