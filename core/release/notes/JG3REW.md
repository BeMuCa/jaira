- Let agents open pull requests on a board by committing `.jaira/pr` with the line `agent`: /jaira-role-pr started by an agent then opens the pull request once every ticket on the branch is in done, instead of handing the create line back. Without the file nothing changes; merging and approving stay a person's either way.
- Name the reviewer an opened pull request asks for in `.jaira/pr-reviewer` (`copilot`, a login, or `org/team`); /jaira-role-pr requests it and answers one round of review comments with its new scripts/pr-round.sh — run 'jaira roles install' to get the script.
- Read the setting back with 'jaira roles list': it prints a 'pr:' line, and --json carries pr, pr_source and pr_reviewer.
- Ask 'jaira roles pr-gate <remote>/<branch>' whether an agent may open the checked-out branch's pull request: exit 0 only when `.jaira/pr` says agent and every ticket the branch's commits name is in done or filed into the logbook, exit 3 naming the ticket that holds it otherwise — a rejected ticket, or a handle this clone does not know (fetch first), holds it too.
- Open a pull request as an agent with 'scripts/pr-round.sh open <owner/repo> <remote> <branch> <title> <body-file>': push the branch first — it opens nothing unless the checkout is the pushed tip of its branch, then runs the gate and opens nothing when the gate refuses; exit 4 only ever means the reviewer could not be requested, a sign-in that runs out mid-run exits 3; two sessions answering the same review thread at once now leave one answer.
- Commit `.jaira/pr-when` with the line `signoff` where your project reviews on the pull request itself: an agent then opens it once every ticket on the branch is in signoff, and a ticket goes to done only after 'scripts/pr-round.sh settled <owner/repo> <number>' finds no open thread, no requested review and no review requesting changes. Without the file the pull request still opens after done; 'jaira roles list' shows it as pr_when.
- ! Commit `.jaira/pr` and `.jaira/pr-when` into your base branch (master) before relying on them: 'jaira roles pr-gate' now reads both as the base holds them, so a file only on your disk or only on the feature branch keeps a person opening the pull request.
- 'scripts/pr-round.sh open' now passes `--head <account>:<branch>` from a fork (the branch alone into its own repository), with the account read off the push URL, and checks the tip where `git push` sends it; a push URL without an account exits 3 and opens nothing — run 'jaira roles install' to get the script.
