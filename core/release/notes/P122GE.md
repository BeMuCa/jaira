- A worker or dispatcher whose ticket reaches signoff (or another person's lane) now keeps its Herdr tab for the prompt cache's window instead of closing it: `close-tab.sh` prints `kept <ticket>: cache warm until HH:MM`, so a give-back within that hour reaches the same worker; `reap.sh` (the cockpit runs it every 10 minutes) closes the tab once the window is over or the ticket is done — set `JAIRA_CACHE_WINDOW` (seconds, default 3600) to change the window.
