- Run a plugin with `jaira <id> [args...]`: jaira starts `~/.jaira/plugins/<id>/jaira-<id>` (`.exe` on Windows) with your arguments, stdin, stdout and stderr, sets `JAIRA_ROOT`, `JAIRA_BOARD` and `JAIRA_VERSION`, and exits with the plugin's exit code; jaira's own commands always win over a plugin of the same name, and nothing on PATH is ever started (docs/PLUGINS.md).
- Subscribe a plugin to `create`, `move`, `claim` and `set` with `"events"` in the `jaira-plugin.json` beside its program: after each such write — moves made in the terminal board included — jaira runs `jaira-<id> event <name>` with the ticket as `show --json` prints it plus `actor` and `from_lane` on stdin, stops it after 5 seconds, and never lets it change the command's result.
- Read a ticket's `external` field from `jaira show --json` and `jaira list --json` instead of parsing the ticket file.
- A merge now keeps a ticket's `external` value from whichever side changed it, instead of reporting a conflict when only the other branch set it.
