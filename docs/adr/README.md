# Architecture decisions

- One file per decision: `NNNN-<area>-<slug>.md`, numbered in order of its Date line; a number is never reused.
- At most 40 lines. Sections in this order: title, `Status:`, `Date:`, Context, Decision, Rejected, Consequences, Sources.
- Status is Proposed (open: the Decision names each side and the tickets behind it), Accepted or Superseded by NNNN.
- A Proposed ADR is a conflict for a person to settle; settling it rewrites Decision, moves the losing side to Rejected.
- Sources name ticket handles and code paths; the ticket holds the detail, the ADR only the choice and why.
- Agents draft ADRs; people accept them. Requirements that follow from a decision go into [../specs/](../specs/README.md).
