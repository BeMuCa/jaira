# Specs
Requirements for jaira, one per line, written as EARS sentences (When / While / If ... then / Where / The ... shall).
Each file stays at or under 100 lines; a requirement ID (`STOR-01`) is unique across all files and never reused.
Agents write and update these files from code and tickets; people do not write specs, they confirm or reject them.

Decisions behind the requirements live in [../adr/](../adr/README.md); a Proposed ADR is an open conflict waiting for a person.
