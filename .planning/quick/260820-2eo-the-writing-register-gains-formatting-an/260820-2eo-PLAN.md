# Quick Task: the register says short, it never said tidy, and it assumed too much

## What is there today, verbatim

The register ships in five places, all one sentence with the same shape:

- `core/board/announce.go:31-37` — the block `jaira init` / `jaira update` writes
  into a repository's `CLAUDE.md`
- `internal/cli/tickets.go:129-136` — `jaira create --help`
- `internal/cli/resume.go:37-38` — `jaira note --help`
- `core/lane/builtin/15-pre-process.md:51-53` — the pre-process lane's prompt
- `docs/AGENTS.md:91-92` — "Leaving a trail"

The sentence: *"Write it as if the reader has mild ADHD — what is wrong first,
short and concrete, names and paths rather than adjectives, no preamble."*

No test pins the wording (`grep "mild ADHD" --include="*_test.go"` is empty), so
this is a text change, not a contract change.

## What the answer to the user's question is

- **mild ADHD: in.** All five places.
- **precise: half in.** "short and concrete, names and paths rather than
  adjectives" is the precision instruction, but nothing says the words must be
  precise as such.
- **cleanly formatted: not in at all.** Nothing anywhere says a word about the
  shape of the text on the page. This is the real gap.
- **written for a beginner: not in.** The reader is only ever described as
  someone who was not in the conversation, which assumes they know everything
  else the writer knows.

## The new canonical sentence

> Write it as if the reader has mild ADHD and knows none of what you know:
> {what} first, short concrete lines, one point each, names and paths rather than
> adjectives, no jargon and no preamble.

Six clauses, one per thing being asked for: ADHD, precision (concrete, names and
paths), formatting (short lines, one point each), beginner (knows none of what
you know, no jargon), and the existing lead-with-it and no-preamble.

The word "dummy" is deliberately not shipped into public CLI help; "knows none of
what you know" and "no jargon" are the same instruction an agent can act on, and
the register is read by strangers cloning the repo. Flag this choice to the user
rather than deciding it silently.
