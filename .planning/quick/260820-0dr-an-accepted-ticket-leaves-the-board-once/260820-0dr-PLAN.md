# Quick Task: archiving has a place in the flow, and nothing said where

## The gap

Asked what happens after a reviewed ticket is moved to done, and where the work
gets pushed, the answer was: nothing says. Verified by grep — `push` appears in
no lane file, nowhere in `core/lane` or `core/gate`, and only twice in README as
team-flow prose. `archive` is documented as a *command* in three places
(README:306, COMMANDS.md:59, SKILL.md:286) and as a key (`x`), but **no document
says when a ticket should be archived**, so a done ticket sits on the board
forever unless someone decides on their own that it should not.

## The rule to write down

An accepted ticket leaves the board once its work is pushed. In that order: if a
ticket is archived before its commits are pushed, a teammate pulls a board that
has forgotten the ticket while the code it describes has not arrived — the one
state this board exists to prevent. A follow-up keeps its link either way:
`follows` survives archiving, and `followUpContext` copies the predecessor's
commits into the new ticket's prose for exactly this reason
(`internal/tui/signoff.go:135-140`).

Nothing is enforced. There is no push check anywhere in the binary and this task
does not add one: archiving is the step after the last lane, not a lane
transition, so a gate has nothing to fire on. This is documentation.

## Established facts (verified this session)

- `core/lane/builtin/50-done.md` is 12 lines of frontmatter with no body.
  `terminal: true`, `requires-commits: true`, and its `description` is the one
  sentence a reader sees. A body would be dead: `lane.go:244` turns a lane body
  into its `Prompt`, and `agentic: false` means no prompt is ever dispatched.
- Every built-in description is one short sentence; done's is the longest already.
- `jaira archive` moves the file to `.jaira/archive/`, deletes nothing, and
  `jaira restore` puts it back.
- Editing a built-in lane changes the embedded copy only. A project that has its
  own copy of `done` keeps the old text until `jaira lanes use done --force` —
  the only refresh path (HANDOFF, 4f198f3).
- The agent loop in `docs/AGENTS.md:10-53` ends at "hand the work on" (move to
  review). Nothing follows it.
- `.claude/skills/jaira/SKILL.md:282-289` has a "Taking a ticket off the board"
  section: three commands, no when.
